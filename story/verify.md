# 出圖驗收規則（給機器判讀用）

這份是餵給視覺模型的驗收提示詞正本。跑法看 [`scripts/verify_pages.py`](../scripts/verify_pages.py)。

**這份跟 [`story/README.md`](README.md) 的角色特徵表不是同一件事。** 那份是給生圖用的：把「短毛、沒有蓬鬆圍領」寫進 prompt，能逼模型畫對。這份是給驗收用的：同一句話拿來事後判讀反而會誤判，因為這部作品的畫風每隻貓都毛茸茸，毛量在畫面上分不出誰是誰。**驗收只能用離散、看得見的道具當判準，不要用體態、毛量、體型這種連續量。**

規則改動一律要跑一次回歸集（`python3 scripts/verify_pages.py --regression`），確認陽性還抓得到、負控制沒有被誤殺。只看抓到幾個會嚴重高估品質。

## 提示詞正文

以下整段（`RULES` 到檔尾）會原封不動送給模型，前面加上要驗的那張漫畫頁。

<!-- RULES -->
你是一部漫畫的出稿驗收員。以下是這部作品的角色識別特徵（正典），逐條比對這張漫畫頁，找出違規。

角色識別特徵：
- 小鳥不啾：全劇唯一的長毛貓（蓬鬆圍領＋耳簇毛）、體型最大、深藍金邊法袍、頂端大藍寶石的金法杖。圓形細金框眼鏡，全劇只有她戴。
- 小白++：褐虎斑、短毛（沒有蓬鬆圍領、沒有耳簇毛）、身形比小鳥不啾小一號、銀色板甲＋紅圍巾披風。不戴眼鏡，頭上沒有頭帶。
- 中年攻城屍：白虎斑、深藍武士鎧、紅繩腰帶、胸前圓形金牌刻著一個「貓」字（畫背影時只看得到繞過肩頸的鎖鍊，金牌本身看不到）。
- 里歐：橘虎斑、黑色連帽斗篷、上面滿是金色肉球扣。
- 荒坂小次郎：巨大暗棕長毛貓、發光紅眼、黑紅披風、胸前圓形紋章是金色厚框＋黑底＋紅色三球。

檢查項目：
A. 眼鏡有沒有戴在小鳥不啾以外的角色身上？其他四隻各有獨有配件，用配件認人，不要用毛量或體型（這部作品每隻貓都畫得毛茸茸，毛量分不出誰是誰）：小白++＝銀色板甲＋紅圍巾披風；中年攻城屍＝深藍武士鎧＋胸前刻「貓」字的圓形金牌；里歐＝黑色連帽斗篷＋金色肉球扣；荒坂小次郎＝巨大暗棕長毛＋發光紅眼＋黑紅披風。戴眼鏡的那隻若身上有以上任何一組配件，就是違規。若都沒有，那就是小鳥不啾，合格（她在特寫格裡可能看不到法杖或鳥，那不是問題）。
C. 對白框裡的中文有沒有不成詞的錯字？（例如把「完蛋」寫成「完旦」、把「嗶」寫成「逼」）只在你能清楚讀出字形、而且確定那個詞不成立時才判違規；字太小或不確定就算合格。
D. 有沒有狀聲字、簽名、浮水印、頁碼，或把中文對白翻成英文另貼一份？世界裡本來就有的英文 UI 文字（螢幕、進度條、橫幅上的字）不算違規。

逐項簡短回答 A C D，每項寫「合格」或「違規＋在哪一格＋看到什麼」。
最後一行只輸出 VERDICT: PASS 或 VERDICT: FAIL。任何一項違規就是 FAIL。
