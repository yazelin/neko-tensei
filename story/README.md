# 創作規範

這份文件是為了讓下一話不要跑偏。任何人（或任何 AI）要畫新的一話，先讀完這裡再動手。

## 分工

| 誰 | 做什麼 |
|---|---|
| LINE C# 社群群友 | 角色本體（暱稱＝角色）、哏、有時親自作畫 |
| 荒坂小次郎 | 第二話封面（他本人就是那隻紅眼魔王） |

## 一話的製作流程

1. **寫分鏡** — 開 `story/epN.md`，每一頁三格，逐格寫「畫什麼／誰在說什麼」。**對白逐字寫進分鏡，也逐字寫進生圖 prompt。**
2. **生圖** — 用 `story/epN.md` 裡每頁的 prompt，經 codex-imagegen 多參考圖 edit 產出成品頁（含對白），存 `images/epN/NN.webp`。
3. **逐頁驗字** — 放大看每一個對話框，確認沒有簡體字、沒有錯字、沒有多餘的字。有問題就整頁重生。
4. **上站** — `episodes.json` 加一段，跑 `python3 build.py`，bump `sw.js` 版本，commit push。

## 鐵律

**對白跟圖一起生。** 一句台詞要出現在畫面上，就寫進 prompt 裡，讓繪圖模型連對話框一起畫出來。不要事後用程式疊字——疊出來的框跟畫面是兩層東西，看得出來。

**對白一律正體中文（zh-TW）。** prompt 裡要明講 TRADITIONAL CHINESE、要求逐字照抄，並禁止模型自己加字（音效、簽名、頁碼、英文說明都不要）。

**每一頁都要驗字。** 這是機率性輸出，會出錯。錯字的代價是整頁重生，所以一頁的對白不要塞太多、句子不要太長。目前一頁 3～6 句是安全範圍。

外稿封面上的錯字是唯一的例外，做法是**兩步**：先像素級補字（只動那幾個字，背景不重生），**再把補過的圖當參考圖丟回去重生一次**。只補不重生會留下一塊糊掉的補丁——貼上去的字是另一種解析度與筆觸，跟周圍的手繪筆觸對不上，放大就看得出來。重生那一步是讓補丁重新被畫進畫面裡。

重生時 prompt 要寫死「忠實重現、不要重新想像」，並把正確的字再寫一次，否則模型會順手改構圖。

## 角色設定的單一來源

**每次生圖都要把角色設定圖當參考圖傳進去**，不能只靠文字描述——文字寫「圓形金牌」，模型就會畫成肉球牌。設定圖在 `story/refs/`（從 `images/char-*.webp` 的貓世界那半邊裁出來，小次郎那張裁自第二話封面），只有貓、沒有前世、沒有字。

參考圖順序固定：**image 1 一律是 `images/ep1/07.webp`**（鎖畫風、上墨感與手寫黑體字），後面接該頁出場角色的設定圖。prompt 裡要用 `REFERENCE IMAGES:` 逐張標明哪張是誰，模型才對得上。

文字描述也要把**識別特徵寫到字面**，不要只寫類別：

| 角色 | 一定要出現的特徵 |
|---|---|
| 小鳥不啾 | 長毛褐灰緬因貓、**圓形細金框眼鏡（臉上一定看得到）**、深藍金邊法袍、頂端大藍寶石的金法杖、**法杖上停一隻鳥＋頭頂停一隻鳥（見下）**、琥珀眼 |
| 小白++ | 年輕虎斑貓、銀色板甲＋皮帶扣、紅圍巾披風、**光頭沒有頭帶**、大琥珀眼露虎牙 |
| 中年攻城屍 | 白虎斑貓、深藍漆武士鎧、紅繩腰帶、**胸前圓形金牌刻著一個「貓」字** |
| 里歐 | 橘虎斑貓、**黑色連帽斗篷上滿是金色肉球扣** |
| 荒坂小次郎 | 巨大暗棕長毛貓、發光紅眼、黑紅披風、粗金鎖鍊、**圓形紅色紋章（樹在爪上）** |

**「必勝」頭帶是前世限定，貓形沒有。** 三份正典（第一話封面、角色卡貓形側、荒坂小次郎畫的第二話封面）小白++ 頭上都是空的，只有前世那個菜鳥綁著頭帶。要看到「必勝」只能透過內心 OS 的前世小圓框。

所以貓世界裡**唯一獲准出現在對白框以外的文字，就是中年攻城屍金牌上那個「貓」字**。prompt 的禁令要單獨開這一個例外，否則模型會連它一起拿掉。

寫特徵時，「沒有什麼」跟「有什麼」一樣要寫死——寫「光頭、沒有頭帶」比不寫更保險，模型才不會自己補一個上去。

### 小鳥不啾身上的鳥

**她叫小鳥不啾，不是因為她是鳥，是因為鳥會自己來停在她身上。** 前世髮上那枚小鳥髮夾，轉生後變成了真的。

所以規則是：**法杖頭上一定要有一隻鳥，頭頂左側一定要有一隻小鳥**，但**兩隻的品種、顏色與配件每一頁都可以不一樣**——藍白繫領巾的、金翅膀的、繫綠絲帶的黃色小雞都算數。第一話封面、角色卡、第二話封面的鳥本來就長得不一樣，這條設定把不一致變成了設定本身。

牠們從來不叫。這是「不啾」的由來，不用畫，但別讓牠們張嘴。

## 內心 OS 的畫法

角色在心裡吐槽時，可以在他頭上浮一顆小圓框，框裡是他**前世的人類身影**。長相照著 `images/char-*.webp` 左半邊那個人畫。

這是本作的固定語法：**貓形＝現在，人臉＝內心。** 別亂用，一頁最多一次，用多了就不好笑了。第二話第 04 頁是示範。

荒坂小次郎沒有前世側（他的來歷還是謎），所以他不能用這個手法。

## 對話框的形狀跟著劇情走

**不要每一句都用圓角矩形。** 框型是分鏡的一部分，讀者在讀到字之前，先讀到的是框的形狀。分鏡表上每一句都要標它的框型，prompt 裡也一句一句寫出來。

| 情境 | 框型 | prompt 關鍵字 |
|---|---|---|
| 大喊、興奮、勝利 | 爆炸狀尖角框，粗黑邊，字放大 | `SHOUT BALLOON` |
| 一般對話 | 手繪感橢圓，細黑邊，短曲線尾巴 | `OVAL BALLOON` |
| 氣勢弱、傻眼、自暴自棄 | 小而扁的橢圓，抖動或虛線邊，字變小 | `WEAK BALLOON` |
| 震驚、害怕 | 邊緣呈鋸齒抖動的橢圓 | `TREMBLE BALLOON` |
| 內心 OS | 雲朵狀，尾巴是三顆越來越小的圓 | `THOUGHT BALLOON` |
| 魔王發話 | 黑底白字，邊緣帶尖刺，壓迫感 | `DEMON BALLOON` |
| 旁白、話末 | 直角方框——**全頁唯一該用直角的地方** | `CAPTION BOX` |

線條要有手繪感，不要幾何學上完美的形狀。

## 版面

- 每頁 1024×1536，三格橫幅由上而下，白色細間隔。
- 參考圖固定放 `images/ep1/07.webp`，鎖住畫風與手寫感的黑色粗體字。
- 對話框不要壓到角色的臉。
